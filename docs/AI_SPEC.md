# Kai RegAI — AI & Narration Specification

## 1. The Core AI Mandate

The Artificial Intelligence layer in **Kai RegAI** is strictly an **orchestrated narration, synthesis, and natural language presentation system**.

```
+-------------------------------------------------------------------------------+
|                            AI ORCHESTRATION LAYER                             |
|                                                                               |
|  Deterministic InterpretationContext (from Rule Engine + Knowledge Base)     |
|         │                                                                     |
|         ▼                                                                     |
|  System Guardrails & Reflection Framing Injection                             |
|         │                                                                     |
|         ▼                                                                     |
|  Controlled Prompt Assembly (Zero Image Input; Pure Structured Facts)         |
|         │                                                                     |
|         ▼                                                                     |
|  LLM Generation (Empathetic, Nuanced, Culturally Resonant Narration)          |
|         │                                                                     |
|         ▼                                                                     |
|  Factual Verification & Safety Post-Filter                                    |
|         │                                                                     |
|         ▼                                                                     |
|  Structured Narrative Chapters Delivered to Report Engine                     |
+-------------------------------------------------------------------------------+
```

### Critical Axiom
* **The LLM is NOT a palm reader.**
* The LLM has no authority to inspect images, diagnose traits, invent rules, or alter palmistry correlations.
* The LLM's sole task is to take verified, literature-backed interpretations generated by the Rule Engine and weave them into an inspiring, cohesive, and deeply personal reading.

## 3. Strict Safety & Guardrail Directives

All prompt chains must enforce these zero-tolerance constraints:

### Directive 1: No Medical or Mortality Claims
* **Forbidden**: Predicting lifespan, time of death, serious illnesses, surgical outcomes, or fertility/childbearing counts.
* **Reflective Alternative**: The Life Line is discussed strictly in terms of vitality rhythm, lifestyle pacing, stamina, and resilience.

### Directive 2: No Guaranteed Financial or Legal Predictions
* **Forbidden**: Promising lottery winnings, sudden windfalls, bankruptcies, divorces, or legal victories.
* **Reflective Alternative**: The Fate and Sun Lines are framed in terms of vocation alignment, perseverance, public expression, and creative satisfaction.

### Directive 3: No Fatalistic or Anxiety-Inducing Language
* **Forbidden**: Declaring that a broken line, island, or cross indicates an inescapable curse, misfortune, or tragedy.
* **Reflective Alternative**: Traditional warnings are reframed as invitations to mindfulness, periods of introspection, or conscious recalibration of habits.

### Directive 4: Anti-Hallucination Barrier
* The AI must strictly refuse to mention any line, mount, or sign that does **not** appear in the provided `verified_traits` list.
* If a line is missing in the payload (e.g., Fate Line not detected), the AI must **not** invent one.

## 4. Mode-Specific Prompt Architectures

### Mode 1: Hand Scanner Quick Reading Prompt
* **Context**: ~10-second fast scan on mobile.
* **Output Objective**: Concise, punchy, inspiring summary card.
* **Structure**:
  * 1 Signature Archetype Title (e.g., *"The Resilient Architect"*).
  * 3 Key Highlight Bullets (Heart, Head, Life).
  * 1 Reflective Reflection Question for the day.
* **Word Count**: $\le 120$ words.

### Mode 2: Palm Reading Guided Dossier Prompt
* **Context**: 3–7 minute deep personal reading.
* **Output Objective**: Multi-chapter personal narrative that synthesizes Hasta Samudrika concepts (*Atma Shakti*, *Pancha Mahabhuta*) with Western characterological analysis.
* **Structure**:
  * **Chapter 1: The Blueprint**: Elemental constitution, hand shape, and thumb willpower vs reason balance.
  * **Chapter 2: The Compass of the Heart**: Emotional resonance, relational style, and empathy patterns.
  * **Chapter 3: The Architecture of Thought**: Reasoning approach, focus, creative vs pragmatic inclinations.
  * **Chapter 4: The Current of Vitality**: Life energy, lifestyle cadence, resilience.
  * **Chapter 5: Synthesis & Contemplation**: Unified guidance and reflective affirmation.
* **Word Count**: $600 - 850$ words.

## 5. Verification & Output Validation

Every generated report text passes through a deterministic validation filter before delivery:
1. **Banned Term Scanner**: Scans for blacklisted predictive terms (*"you will die"*, *"cancer"*, *"divorce on"*, *"guaranteed riches"*, *"cursed"*).
2. **Entity Consistency Check**: Confirms that cited palm lines match the input features.
3. **Tone Calibrator**: Ensures presence of empowering, reflective framing before the text is handed off to the Report Engine.
