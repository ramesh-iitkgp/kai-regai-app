# Kai RegAI — Monetization & Freemium UX Specification

## 1. Monetization Philosophy: Respectful Value-First Discovery

Kai RegAI avoids aggressive, bait-and-switch paywalls or coercive countdown timers that degrade trust in reflective personal applications.

Instead, the product provides a **generous, high-value free discovery tier** (Mode 1 Hand Scanner), while reserving deep, intensive multi-chapter personal dossiers for the **Kai RegAI Premium** tier.

```
+─────────────────────────────────────────────────────────────────────────────+
|                         TIER BOUNDARY SPECIFICATION                         |
|                                                                             |
|  FREE TIER (Universal Discovery)                                            |
|  ├── Unlimited Mode 1 Hand Scans (~10s experience)                          |
|  ├── 3D Quick Report Card with illuminated lines                            |
|  ├── Top 3 dominant archetypal traits & daily reflection                    |
|  └── Full access to the Learn Library articles                              |
|                                                                             |
|  PREMIUM TIER (Deep Contemplative Guidance)                                 |
|  ├── Unlimited Mode 2 Guided Palm Readings with 5 Interactive Modules       |
|  ├── Multi-Chapter Detailed Palm Dossiers with authentic Sanskrit citations |
|  ├── Bilateral Hand Comparison (Dominant Active vs Passive Innate)          |
|  ├── High-Resolution Branded PDF Dossier Export                            |
|  └── Unlimited Reading History Archive & Evolution Timeline                 |
+─────────────────────────────────────────────────────────────────────────────+
```

## 2. In-App Upgrade Touchpoints (Paywall Triggers)

Paywall sheets are presented contextually only when the user voluntarily seeks deeper value:

1. **Trigger A: Upgrading from Quick Report to Deep Reading**
   * *Location*: Bottom of Quick Report Card (`SCR-SCN-002`).
   * *CTA*: *"Unlock Full Guided Reading"* $\rightarrow$ Displays paywall sheet highlighting deep chapters.
2. **Trigger B: Exporting High-Resolution Styled PDF**
   * *Location*: Share sheet on Detailed Dossier (`SCR-PLM-005`).
   * *Copy*: *"Export your comprehensive multi-chapter dossier as an archival PDF document."*
3. **Trigger C: Bilateral Hand Comparator Tool**
   * *Location*: Readings archive tab (`SCR-RDG-002`).
   * *Copy*: *"Compare the karmic blueprint of your left hand with the active trajectory of your right."*

## 3. Subscription Management & Restoration UX (`SCR-PRF-003`)

* **Transparency Requirements**:
  * Clear pricing terms (e.g. Monthly / Annual subscription or Single Deep Reading Pass).
  * Prominent, unhidden **"Restore Purchases"** button in accordance with Apple App Store Guideline 3.1.1 and Google Play Billing requirements.
  * Clear one-tap link to OS Subscription Management settings.
