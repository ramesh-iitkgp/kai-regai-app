# Kai RegAI — P5.1 Computer Vision Failure Taxonomy
**Product:** Kai RegAI  
**Phase:** P5.1 — Real-Palm Validation & Calibration  
**Document:** Standardized Diagnostic Failure Classification

---

## Standardized Error Classes (F1 to F12)

Every geometric discrepancy, misclassification, or omission observed during real-palm evaluation must be classified into one of the following 12 failure modes:

| Code | Failure Mode | Description | Primary Root Cause | Mitigation Strategy |
| :--- | :--- | :--- | :--- | :--- |
| **F1** | **Wrong Location** | Detected polyline is structurally unrelated to the actual crease. | Erroneous candidate selection or distant noise artifact. | Tighten anatomical search prior boundaries (`startZone`, `endZone`). |
| **F2** | **Parallel Offset** | Detected line follows the crease trajectory but is consistently displaced by $\Delta > 10$px. | Affine rectification offset or incorrect center of rotation. | Re-calibrate palm center and homography coordinate mapping. |
| **F3** | **Fragmentation** | A single continuous real crease is broken into multiple disconnected candidates. | Excessive thresholding or local contrast dip along crease. | Lower gap bridging cost in graph; adjust Hessian scale fusion. |
| **F4** | **Over-Merging** | Multiple distinct real creases (e.g. Head and Heart, or Life and Fate) merge into one continuous path. | Insufficient spur pruning or low binarization threshold at intersection. | Enhance branch point detection and bifurcation severance. |
| **F5** | **Wrong Line Identity** | A real crease is correctly extracted geometrically, but mislabeled (e.g. Head line labeled as Heart line). | Overlapping prior sectors or hand tilt skewing relative coordinates. | Incorporate landmark proximity vectors and orientation gating. |
| **F6** | **Missing Line** | Real crease is clearly visible, but system returns `NOT_DETECTED`. | Detection confidence threshold too high or contrast filtered out. | Calibrate $\tau_{\text{weak}}$ and $\tau_{\text{detection}}$; inspect CLAHE clip limit. |
| **F7** | **False Positive** | System outputs a detected line where no physical crease exists on the hand. | Hallucination on skin folds, lighting shadow, or border edge. | Penalize low ridge response; require minimum structural continuity. |
| **F8** | **Branch Error** | The primary crease is located, but the polyline follows a minor offshoot branch instead of the main trunk. | Graph tracing prioritizing wrong endpoint neighbor. | Weight longest path or highest cumulative Hessian response during graph traversal. |
| **F9** | **Endpoint Error** | Line follows the correct trajectory, but starts or terminates significantly premature or overshoots. | Tracing stops at local shadow transition or extends into wrist skin. | Introduce anatomical landmark termination constraints (e.g. Wrist, MCP). |
| **F10** | **Texture Confusion** | Surface wrinkles, dry skin cracks, hair, or jewelry artifacts are mistaken for major creases. | High-frequency noise passing through fine filter scale. | Increase Gaussian pre-filter $\sigma$; decrease fine scale weight in favor of medium/coarse. |
| **F11** | **Segmentation Error** | Incorrect palm boundary or orientation angle causes the rectified patch to be misaligned or cropped. | Background skin-tone confusion or non-standard hand pose. | Refine inner palmar falloff mask and wrist-to-MCP9 vector computation. |
| **F12** | **Landmark Error** | Mislocalized skeletal landmarks skew the search priors. | Partially folded thumb or extreme camera perspective skew. | Add geometric landmark sanity checks (e.g. MCP collinearity). |

## Diagnostic Triage Workflow

```text
Detected Line vs Ground Truth
         │
         ├── Does GT line exist?
         │     ├── NO  ──→ Is line detected? ──→ YES: [ F7: False Positive ]
         │     │                              ──→ NO:  [ Correct Rejection ]
         │     └── YES ──→ Is line detected? ──→ NO:  [ F6: Missing Line ]
         │                                    ──→ YES: Evaluate Geometry
         │
         ├── Is line orientation / type correct?
         │     ├── NO  ──→ [ F5: Wrong Line Identity ]
         │     └── YES ──→ Measure Mean Point-to-Curve Distance (D)
         │
         ├── Distance D > Threshold?
         │     ├── Consistently offset alongside crease ──→ [ F2: Parallel Offset ]
         │     └── Far away across other anatomy       ──→ [ F1: Wrong Location ]
         │
         ├── Start / End offset > Threshold?
         │     └── [ F9: Endpoint Error ]
         │
         └── Polyline fragmented into short segments?
               └── [ F3: Fragmentation ]
```
