## 1. Evaluation Methodology

Phase P5.1 establishes reproducible benchmarking against real human palm photography:
* **Ground-Truth Centerline Comparison:** Polylines traced along visible crease furrows by human experts conforming to [P5.1_ANNOTATION_GUIDELINES.md](file:///Users/Hp/Documents/Kai%20RegAI%20%28clone%29/docs/p5/P5.1_ANNOTATION_GUIDELINES.md).
* **Objective Error Metrics:**
  * **Symmetric Mean Distance:** Average nearest-neighbor Euclidean distance between detected points and ground-truth points:
    $$\bar{d} = \frac{1}{2}\left(\frac{1}{|P|}\sum_{p\in P} \min_{g\in G}\|p-g\| + \frac{1}{|G|}\sum_{g\in G} \min_{p\in P}\|g-p\|\right)$$
  * **Median Point-to-Curve Distance:** Resilient against endpoint overshoots and local branch offshoots.
  * **Symmetric Hausdorff Distance:** Maximum worst-case localized deviation:
    $$H_{\text{sym}}(P, G) = \max\left(\max_{p\in P}\min_{g\in G}\|p-g\|, \;\max_{g\in G}\min_{p\in P}\|g-p\|\right)$$
  * **Normalized Error Metric:**
    $$E_{\text{norm}} = \frac{\bar{d}}{W_{\text{palm}}}$$
  * **Endpoint Offset:** Deviation between detected start/end vertices and reference anatomical origins.
  * **Absence Detection Accuracy:** Specificity and true negative rate on absent Fate and Sun lines.

## 2. Validation Dataset Structure

Located under `cv/real-validation/`:
* `raw/`: Uncompressed/JPEG mobile photographs (protected by `.gitignore` to preserve biometric privacy).
* `normalized/`: Resolution-clamped and orientation-tagged image caches.
* `annotations/`: Standardized JSON ground-truth definitions (`PalmAnnotation`).
* `predictions/`: Full P5 vision pipeline outputs (`PalmVisionResult`).
* `overlays/`: Side-by-side SVG/HTML comparison artifacts displaying ground truth (green) vs detected lines (colored).
* `metrics/`: Granular quantitative error matrices (`real_validation_summary.json`).
* `reports/`: Aggregated evaluation summaries and calibration sweep logs.
