# P5.2 — Capture Quality & Retake Decision Engine Specification

## Kai RegAI — Palm Computer Vision Engine (P5.2)

### 1. Architectural Philosophy
In mobile palmistry applications, user-uploaded photographs and real-time camera captures exhibit wide variances in capture hygiene. When an image fails to provide sufficient anatomical crease evidence, an AI system must never guess, invent decorative polylines, or silently fail.

Phase P5.2 formalizes a deterministic two-tiered gating architecture:
1. **Tier 1: Optical Image Quality (`ImageQualityAnalyzer`)**: Evaluates raw sensor data for focus, illumination, contrast, glare, and resolution before computer vision execution.
2. **Tier 2: Usability & Positioning (`PalmUsabilityValidator`)**: Evaluates localized hand landmarks, scale fraction, border clipping, tilt angles, and regional visibility.
3. **Decision Layer (`RetakeDecisionEngine`)**: Synthesizes optical metrics and positioning attributes into user-actionable instructions.

---

### 2. Retake Action Categories

Every capture processed by `PalmVisionEngine` produces a structured `RetakeDecision`:

```typescript
type PalmUsabilityAction = 
  | 'PROCEED'               // Optimal capture; pipeline proceeds to full interpretation
  | 'RECAPTURE'             // Optical failure (blur, glare, dark, overexposed); retake needed
  | 'USER_CORRECTION'       // Hand positioning issue (tilt, distance, multi-hand, border clipping)
  | 'INSUFFICIENT_EVIDENCE';// Image passed optical checks but palmar area lacks distinct creases
```

### 4. Canonical Contract: `RetakeDecision`

The retake decision is embedded directly in every vision result:

```javascript
{
  action: "USER_CORRECTION",
  needsRetake: true,
  primaryMessage: "Place your palm flat and upright facing the camera.",
  detailedGuidance: [
    "Hold your hand upright with fingers pointing upward."
  ],
  diagnosticCode: "F11_EXCESSIVE_TILT"
}
```

---

### 5. Mobile & Client Integration Guidelines
1. **Camera Preview Overlay**: The mobile capture viewfinder subscribes to `RetakeDecision.primaryMessage`. Warnings display as subtle, non-intrusive floating badges.
2. **Zero Hallucination Barrier**: If `needsRetake === true` and `action !== 'PROCEED'`, the reading session state machine blocks entry into the interpretation engine and offers a 1-tap Retake flow.
3. **Epistemic Integrity**: Under-evidence diagnostics are never disguised as palmistry personality traits (e.g., poor lighting is never interpreted as a "short lifespan").
